# Handoff — 跨会话自主任务交接与审计技能

本技能负责在会话即将结束、达到轮数上限、或前序会话突发异常（如 429 频控/连接中断）时，执行专业级审计与交接提炼，输出标准高保真交接文档，确保接力智能体（Successor Agent）能够零磨损无缝接管任务。

## 核心职责

当你被激活或收到交接指令时，表明当前长耗时任务正处于跨会话接力期。你的核心任务是：
1. 梳理前序会话执行历程与真实技术推演；
2. 提炼出结构严谨、主客观分离、包含深度技术见解的 Markdown 交接文档；
3. **调用 `write_file` 工具原生落盘**至目标路径：`<工作区根目录>/.cph/handoffs/handoff-<会话ID>.md`；
4. 写入完成后简要汇报已落盘状态，交由接力调度器顺畅唤起接力智能体。

---

## 交接文档核心规范 (High-Fidelity Specification)

高质量的交接文档注重主客观信息分离与深度技术沉淀，避免机械流水账，完整涵盖以下核心维度：

### 1. 【任务目标与背景 (Task Goal & Context)】
- 完整记录用户最初下达的核心目标、业务要求与约束条件；
- 明确标注当前工作的宿主环境、工作区绝对路径与基准分支。

### 2. 【阶段性技术审计发现与核心见解 (Review Draft & Mental Model)】
- **AI 架构思考与见解**：提取前序会话中 AI 对已读源码、模块架构、技术债务与业务逻辑的**实质性专业研判意见与重构建议**（若前序包含 `HANDOFF_MEMO:`，完整提炼其核心洞察）。明确记录具体发现了什么、有何风险或改进方向；
- **阶段性产物引用**：主动探测工作区是否存在 `.cph/review_draft.md`、审查报告草稿或其他阶段性产物文件；若存在，将其关键章节与审计备忘录直接作为证据锚点嵌入或引用。

### 3. 【已验证客观事实与物理基线 (Verified Facts & Baselines)】
- 盘点前序会话中所有**已执行成功**的物理工具调用与关键探索结论；
- 明确指出哪些假设已被证实有效、哪些环境依赖已安装/验证（如 Node、.NET、Git 配置）；
- 给出明确的文件路径或命令输出证据。

### 4. 【已探明的反模式与暗坑警示 (Anti-Patterns & Caveats)】
- 明确列出代码库中已识别的代码坏味道、设计缺陷（如超过 1,000 行大文件、散落条件分支、缺失超时重试、竞态条件等）；
- 记录前序已探明的无效路径与试错经验，供接力者参考。

### 5. 【关键卡点、报错与最新诊断 (Current Blockers & Diagnostics)】
- 若包含【事故黑匣子快照】或末期失败调用，重点提取最后 2 轮的原始报错信息（如编译错误、网络 429 频控、文件找不到等）；
- 结合模型的思考研判，给出清晰的断点根因分析（Root Cause Analysis），指出前序尝试为什么会受阻。

### 6. 【已变更/生成文件清单 (Modified & Created Artifacts)】
- 聚合列出前序会话中通过 `write_file`、`edit`、`patch_file` 创建或修改过的全部文件绝对/相对路径；
- 说明每个变更文件的当前状态（例如已完成、部分打补丁、待编译验证等）。

### 7. 【接力第一优先级待办事项 (Actionable Next Steps for Successor)】
- 向接力智能体（Successor Agent）下达清晰、具体的首要攻坚指令；
- 指明下任接力者应直接切入的具体文件与逻辑，无缝推进后续未完事项；
- 给出上下文封闭的明确首步指令（如“直接打开 X 文件的 Y 行开始重构”）。

## 执行流程

1. **解析输入上下文**：
   - 提取前序会话中 AI 的真实思考、`HANDOFF_MEMO:`、以及工具执行记录；
   - 探测工作区 `.cph/review_draft.md` 等阶段性产物；
2. **提取会话标识与目标路径**：
   - 提取 `<sessionId>`（若未显式指定，使用当前会话 ID 或根据时间戳生成 `ses_handoff_<timestamp>`）；
   - 目标路径为：`.cph/handoffs/handoff-<sessionId>.md`；
3. **调用 `write_file` 工具落盘**：
   - 使用 `write_file` 将格式化好的完整 Markdown 文本写入目标文件；
4. **输出交接完成摘要**：
   - 在回复中向用户和接力调度器汇报：“✔ 已生成高保真交接文档并保存至 `.cph/handoffs/handoff-<sessionId>.md`，接力智能体可随时接续！”
